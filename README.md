# 📧 Automated Cold Outreach RAG System

A fully integrated, agentic **Retrieval-Augmented Generation (RAG)** platform that automates cold outreach by analyzing website data, identifying potential leads, and delivering **personalized service offerings via email**.  

---

## 🔹 Project Description

This project is built to remove the manual burden of researching leads, drafting emails, and scaling outreach campaigns.  

At its core, the system:  
- 🌐 **Scrapes & analyzes client websites** to understand their business context.  
- 🧠 **Uses a RAG-powered AI engine** to generate personalized outreach messages.  
- 📧 **Delivers messages via a custom email service** for scalable cold outreach.  

By combining website intelligence with contextual message generation, the system ensures **better targeting, higher engagement, and reduced effort** compared to traditional outreach.  

---

## ⚙️ Technology Stack

- **Frontend**: [Next.js](https://nextjs.org/) (React)  
- **Backend**: [FastAPI](https://fastapi.tiangolo.com/) (Python)  
- **Database**:  
  - [PostgreSQL](https://www.postgresql.org/) via [Prisma ORM](https://www.prisma.io/) → for lead management  
  - [Supabase](https://supabase.com/) Vector Store → for storing website embeddings  
- **Email Service**: Custom MCP (Model Context Protocol) Server  
- **AI Engine**: Agentic RAG pipeline using **embeddings + contextual generation**  

---

## ❗ Why This Matters

Cold outreach is **time-consuming, stressful, and inefficient** for most businesses:  
- Manual research of leads is slow.  
- Generic outreach emails result in low response rates.  
- Scaling campaigns often increases cost without improving outcomes.  

This system solves those challenges by:  
- ✅ Automating research through **website analysis**  
- ✅ Crafting **personalized outreach at scale** with AI  
- ✅ Delivering **higher engagement & conversions** without additional headcount  

---

## 🚀 Features

- 🔍 Website scraping & semantic analysis  
- 📦 Vector-based knowledge store with Supabase  
- 🧠 Agentic RAG system for contextual email generation  
- 📧 Custom MCP-powered email delivery  
- 📊 Lead storage & management with PostgreSQL
